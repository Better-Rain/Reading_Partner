# Reading Partner 0.1.0

发布日期：2026-05-04

这是 Reading Partner 的第一个可分发版本，面向 Windows x64，以便携版 exe 形式发布。

## 主要功能

- PDF 阅读：打开本地 PDF、翻页、缩放、拖动浏览。
- 阅读标记：高亮、批注、书签、颜色预设、悬浮提示、时间戳。
- 文档搜索：搜索 PDF 文本，点击结果后跳转并显示临时定位高亮。
- 生词与词典：支持导入 ECDICT/StarDict，词典联想搜索，加入当前 PDF 生词本。
- AI 辅助阅读：选中文本翻译/解释/总结，文档问答，共读长对话，支持 DeepSeek 等 OpenAI 兼容接口。
- 阅读记录共享：导出/导入批注、高亮和书签，不导出 AI 对话与 AI 生成内容。
- 简单身份：用户可设置阅读身份，新建批注、高亮和书签会记录作者名。
- 撤销：批注、高亮、书签的新建、删除、编辑支持 `Ctrl+Z` 撤销。

## 分发文件

本地构建后生成：

- `release/Reading Partner 0.1.0.exe`：Windows x64 便携版，可直接运行。
- `release/win-unpacked/Reading Partner.exe`：解包目录版本，主要用于本地验证。

## 构建命令

```powershell
npm run dist
```

如果 Windows 普通用户权限无法解压签名工具，本项目已关闭 Windows 可执行文件资源编辑以保证初版便携包可以稳定生成。因此当前版本使用默认 Electron 图标，后续可补应用图标和签名流程。

## 已知限制

- 当前版本未做代码签名，Windows 可能显示安全提示。
- 便携版的应用数据仍存放在系统用户数据目录，不会自动跟随 exe 文件移动。
- AI Key 不会导出，也不会写入阅读记录共享文件。
