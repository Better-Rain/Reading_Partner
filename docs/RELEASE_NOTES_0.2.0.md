# Reading Partner 0.2.0

发布日期：2026-05-09

这是 Reading Partner 的第二个本地可分发版本，重点增强阅读进度、批注体系、生词联动、AI 共读对话和 AI 辅助批注能力。面向 Windows x64，以便携版 exe 形式发布。

## 主要更新

- 阅读进度：自动保存并恢复每本文档的上次阅读页；无记录或异常页码会回到第一页。
- PDF 阅读体验：优化缩放闪烁、翻页预加载、文档库长标题省略号显示。
- 批注显示：合并同一行相邻批注矩形，避免空格把批注拆成多个小方块。
- 批注管理：笔记默认按最新编辑时间倒序；所有批注类型都支持编辑颜色。
- 筛选机制：笔记筛选改为多开关模式，支持高亮、批注、书签、生词批注组合筛选。
- 生词联动：生词和对应批注建立关联；删除其中一方会同步删除另一方；生词批注使用下划线样式区分。
- 浮窗定位：PDF 批注浮窗会根据鼠标位置和页面边界自动调整，减少右侧或底部遮挡。
- AI 对话：进入对话后默认滚动到最新消息；支持重新发送和停止输出。
- AI 上下文：当前页片段优先进入上下文，长上下文 Provider 会携带更多历史消息和文档片段。
- AI 模型：配置面板支持直接修改 Provider 的模型名，便于切换 DeepSeek 等兼容模型。
- AI 关联选区：带选区提问时，AI 回答可保存为用户作者的选区批注，并支持 Markdown 渲染。
- AI 辅助批注：明确要求“批注”时会走 AI 批注流程，避免和普通选区回答批注互相干涉。
- AI 批注权限：AI 可更主动创建候选批注，支持词汇、段落、页边、总结、问题等 scope，最多 5 条，并可自行选择可读颜色。

## 分发文件

本地构建后生成：

- `release/Reading Partner 0.2.0.exe`：Windows x64 便携版，可直接运行。
- `release/win-unpacked/Reading Partner.exe`：解包目录版本，主要用于本地验证。

## 构建命令

```powershell
npm run dist
```

## 升级说明

- 本版本继续使用本机用户数据目录中的数据库和 API Key 配置。
- 如果已配置本地词典、AI Provider 或阅读记录，升级 exe 后应继续沿用原有数据。
- AI 生成的批注仍作为候选操作显示，可由用户选择保留或撤销。

## 已知限制

- 当前版本未做代码签名，Windows 可能显示安全提示。
- 便携版的应用数据仍存放在系统用户数据目录，不会自动跟随 exe 文件移动。
- GitHub 发布上传依赖本机网络和认证环境；如果网络无法连接 GitHub，需要先本地构建，再恢复网络后上传发行文件。
