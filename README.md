# Reading Partner

Reading Partner 是一个面向大部头 PDF 文献、英文原著和研究型阅读的桌面应用。它把 PDF 阅读、文本搜索、高亮、批注、书签、生词本、本地词典、AI 解释、文档问答和连续共读对话放在同一个工作流里，目标是让电脑成为一个可以陪你读书、查词、定位证据和整理思路的阅读伙伴。

当前版本优先支持 Windows。已构建的便携版程序通常位于：

```text
release/Reading Partner 0.2.0.exe
```

双击即可运行，无需安装。

## 适合谁使用

- 阅读英文原著、论文、教材、技术文档，需要随手查词、翻译和做笔记。
- 阅读很长的 PDF，希望搜索后能快速定位到页面中的具体片段。
- 希望把选中的段落交给 AI 做解释、翻译、总结或连续追问。
- 希望 AI 不只是回答问题，也能在必要时帮你创建少量辅助批注，并由你决定保留或撤销。
- 希望把高亮、批注、书签导出给别人，让对方在同一本 PDF 上复现你的阅读痕迹。
- 希望数据本地优先，避免把整本 PDF 默认上传给模型。

## 快速开始

1. 打开 `Reading Partner 0.2.0.exe`。
2. 点击左上角的打开按钮，选择一本 PDF。
3. 等待状态栏显示“文本索引完成”或“文本索引已就绪”。
4. 在右侧面板切换“笔记、搜索、AI、词汇、配置”开始使用。

首次使用 AI 时，进入“配置”面板，在 DeepSeek 或其他兼容服务中填写 API Key。API Key 保存在本机，不会进入 Git 仓库，也不会导出到阅读记录文件。

## 常见使用场景

### 1. 阅读英文段落并让 AI 解释

1. 在 PDF 中拖选一段英文。
2. 浮动工具栏会出现高亮、批注、翻译、解释、生词等按钮。
3. 点击“解释”，AI 会根据选中文本生成说明。
4. 如果需要继续追问，进入右侧“AI”面板，新建或打开一个共读对话。

可以这样提问：

- “这段话的关键概念是什么？请先解释句子结构，再解释思想含义。”
- “这段和上一节的论证关系是什么？”
- “请用中文解释，但保留重要英文术语。”
- “把这段改写成适合复习的阅读笔记。”

### 2. 使用连续共读对话

AI 面板支持类似聊天式的长对话。你可以先创建一个对话，但只有真正发送第一条消息后，它才会保存为正式对话。应用会根据首条消息自动生成标题，你也可以手动改名。

适合的用法：

- 按章节建立对话，例如“第一章核心概念”“第三节公式推导”。
- 选中 PDF 原文后发送问题，让 AI 同时参考选区和历史对话。
- 针对同一段内容连续追问：“这句话怎么断句？”“作者为什么这样论证？”“有什么反例？”

### 3. 让 AI 辅助创建批注

AI 在回答问题时已经知道自己可以创建少量辅助批注。它不会每次都创建，只有当某个概念、词汇、段落观点或易错点值得长期保留时，才会在 PDF 上生成批注。

当 AI 创建批注后，对话中会显示本次操作卡片：

- 点击“保留”：接受 AI 创建的批注。
- 点击“撤销”：删除本次 AI 创建的批注。

AI 创建的批注会注明使用的模型，例如“模型：deepseek-...”。普通用户的 `Ctrl+Z` 撤销不会影响 AI 操作卡片，AI 批注请通过卡片中的“保留/撤销”处理。

### 4. 高亮、批注和书签

1. 选中 PDF 原文。
2. 点击“高亮”保存荧光笔标记。
3. 点击“批注”写下自己的理解。
4. 点击“书签”记录当前页。
5. 鼠标移动到页面中的高亮或批注上，会显示浮窗。
6. 点击批注或高亮，可以固定浮窗；拖动 PDF 时浮窗不会自动消失。

快捷键：

- `H`：给当前选区添加高亮。
- `N`：打开当前选区的批注输入框。
- `D`：切换手型拖动模式。
- `Ctrl+Z`：撤销上一条手动创建或编辑的高亮、批注、书签操作。

### 5. 筛选和管理大量笔记

右侧“笔记”面板支持紧凑筛选条：

- 一键切换全部、高亮、批注、书签。
- 只看当前页。
- 显示或隐藏 PDF 页面上的标记。
- 展开高级筛选后，可以按作者、排序方式、搜索关键词筛选，也可以把筛选同步到 PDF 显示层。

每条笔记默认折叠，适合笔记很多的长文档。展开后可以编辑内容、修改颜色、跳转到对应页或删除。

### 6. 搜索文档并快速找到位置

1. 进入右侧“搜索”面板。
2. 输入关键词或短语。
3. 点击搜索结果。
4. 应用会跳到对应页，并用临时蓝色高亮标出命中位置。
5. 点击“结束”可以清空搜索结果并退出临时定位模式。

适合搜索：

- 术语：`swarm intelligence`
- 概念：`paradigm shift`
- 缩写：`MAS`
- 作者名、公式名或章节关键词

### 7. 查词和整理生词

进入“词汇”面板后，可以导入本地 ECDICT 或 StarDict 词典。导入后，词典搜索框支持自动联想和候选词条。

常用流程：

1. 在词典搜索框输入单词。
2. 查看候选词条和释义。
3. 需要长期复习的词，加入当前 PDF 的生词本。
4. 在 PDF 中选中单词或短语，也可以通过浮动工具栏中的“生词”加入生词本。

词条会尽量拆分显示音标、词性、释义、变形、标签和频率信息，避免把原始词典内容全部堆成一段纯文本。

### 8. 共享阅读记录

Reading Partner 支持导出和导入阅读记录，方便把自己的阅读痕迹分享给别人。

导出：

1. 打开 PDF。
2. 进入“笔记”面板。
3. 点击“导出记录”。
4. 应用会生成一个 JSON 文件，包含高亮、批注、书签、颜色、时间和作者身份。

导入：

1. 对方先打开同一本 PDF。
2. 进入“笔记”面板。
3. 点击“导入记录”。
4. 选择你分享的 JSON 文件。

阅读记录导出不包含 API Key，也不包含 AI 对话历史。

### 9. 设置阅读身份

进入“配置”面板，找到“阅读身份”，填写自己的名字或昵称。之后新建的高亮、批注和书签都会带上这个身份，方便多人共享阅读记录时区分作者。

这个身份不是账号系统，也不用于安全认证，只是类似 Office 批注作者名的轻量署名。

## 数据与隐私

- PDF 文件路径、批注、书签、生词、搜索索引和 AI 对话记录默认保存在本机。
- 文档问答不会默认把整本书上传给模型，而是先从本地索引中检索相关片段。
- API Key 通过应用配置界面保存，不应写入 README、源码、文档或其他会提交到 GitHub 的文件。
- 导出的阅读记录只包含阅读标记，不包含 API Key。

## 当前限制

- Windows 版本尚未做代码签名，首次运行可能出现系统安全提示。
- PDF 文本抽取依赖 PDF 本身的文字层；扫描版图片 PDF 需要后续 OCR 功能支持。
- AI 辅助批注依赖模型输出质量，建议把它当作候选笔记，由你决定保留、撤销或继续编辑。
- 便携版不会把用户数据保存在 exe 旁边，应用数据仍保存在系统用户数据目录。

## 维护与重新打包

普通用户不需要执行这些命令。只有本地开发或重新打包时才需要：

```powershell
npm install
npm run dev
npm run typecheck
npm run dist
```

重新生成图标：

```powershell
npm run icons
```
